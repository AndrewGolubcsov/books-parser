# Парсер каталога книг -> Excel

Демо для портфолио. Собирает весь каталог [books.toscrape.com](https://books.toscrape.com) (сайт сделан специально для практики парсинга) и сохраняет в аккуратную таблицу Excel.

## Что умеет
- обходит все страницы каталога по пагинации
- при `--details` заходит в карточку каждой книги: категория, остаток, UPC, описание (в 8 потоков)
- повторяет запрос при ошибках сервера, делает паузы между страницами
- Excel: шапка, закреплённая строка, автофильтр, ширина колонок, отдельный лист со сводкой

Результат: 1000 книг с карточками примерно за минуту — пример в `books.xlsx`.

## Запуск
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python parser.py --details
```

Параметры: `--pages N` — только первые N страниц, `--workers N` — число потоков, `-o файл.xlsx` — куда сохранить.

## Стек
Python 3.12, requests, BeautifulSoup4, openpyxl, ThreadPoolExecutor.
